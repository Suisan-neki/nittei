# Nittei

変則的な大学の時間割を、日付ベースでそのまま管理するためのiOS向けSwiftUIアプリです。

## 入っている機能

- 2026年4月から2027年3月までの月間カレンダー表示
- 日付タップで、その日の予定を`何限`順に一覧表示
- `科目`と`場所`の登録
- `テストの日`を赤系で強調表示
- 右下ボタンからの簡単追加
- 端末内保存 `UserDefaults`
- 歯学科3年生の第3・第4ターム時間割と学年暦
- 振替授業・試験期間・休業期間・補講予備日の表示

## 後期時間割の出典と扱い

令和8年度 歯学部歯学科授業時間割（2026/9/11版）と令和8年度学年暦を参照しています。
授業名・教室・掲載日程を登録し、10/16は月曜、1/6は火曜、1/14は月曜の授業に切り替えます。
祝日、冬季休業（12/26〜1/5）、1/15の休講日は後期の授業を生成しません。

表示は既存の90分単位に合わせています。アプリの1限はPDFの1・2コマ、
2限は3・4コマ、3限は5・6コマ、4限は7・8コマ、5限は9・10コマです。

臨床見学演習・実習Ⅱは実施日が別途指示のため、候補枠の日に注意書きを表示します。
試験期間や補講予備日の色は、個別の試験・補講があることを意味しません。
科目別の日程はもみじ・担当教員から確認し、判明した授業や試験を手動追加してください。
PDFに記載された通常授業の範囲は試験期間末尾まで含むため、そのまま登録しています。

更新時は固定IDの初期データを追加・更新します。手動追加した予定は保持します。

## 想定

- 繰り返し時間割ではなく、変則日程を日付ごとに積んでいく
- バックエンドなし
- まずはフロントエンドを素早く試す用途

## 開き方

```bash
xcodegen generate
open Nittei.xcodeproj
```

## ビルド確認

```bash
xcodebuild -project Nittei.xcodeproj -scheme Nittei -destination 'generic/platform=iOS Simulator' build
```

時間割・保存データ更新の検証（macOS / Swift 6）：

```bash
bash scripts/validate-schedule.sh
```
